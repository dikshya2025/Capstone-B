# Secure Project Catalogue Management

## Project Overview

Secure Project Catalogue Management is a system for managing and organising project information securely.

The project aims to provide an organised catalogue where authorised users can manage, view, search, and review project information.

## Project Objectives

* Manage project information in an organised way.
* Protect project information from unauthorised access.
* Allow users to view and search project information.
* Support project review and management.
* Maintain accurate project data.
* Prepare the system for future database and backend development.
